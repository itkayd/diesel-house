Diesel House

A working mock of the game built from the real LimeZu pixel sheets: a furnished, lit house, the HUD, door nameplates, knocking, room chat, settings and the character picker. Walk around below. Everything on this page uses theme.css and sprites.json, which live next to it in design/game/.

WASD / arrows or hold the mouse to walk · click someone in your room for their volume · Space = talk in push-to-talk · the joystick appears in phone view

How Claude Code should use this

This page is the target look for Phase 4.6 onwards. Match it; don't redesign it. Where the game and this page differ, this page wins on visuals and NEXT.md wins on behaviour.

Port to Phaser
  1. Furniture: one sprite per piece. Depth = bottom y (same rule as players), rugs depth 0, wall items depth 1. Collide on the bottom 8 px of solid pieces only, never rugs or wall items.
  2. Night lighting: full-map rectangle #8a7fae with MULTIPLY blend, then a soft radial light image per lamp with SCREEN/ADD blend (colours in ROOMS). Occupied rooms get an extra warm pool.
  3. Nameplates: over each doorway. Wood board = name + mood icon; lock/knock icon when not open; up to 4 heads then "+N".
  4. Name tags and bubbles: world-space, pixel font, never blurred (setResolution(4)).
  5. HUD: plain DOM over the canvas with the .dh-* classes. Chat is a side sheet on desktop and a bottom sheet under 640 px.
  6. Characters: this page shows only the 4 LimeZu people. The chibi sheets are left out on purpose (their artist asks that they aren't fed to AI); in the game they use the same tag, ring and portrait styles.

Tokens

One accent (lamp). Everything else is night, plum panels and cream text. Status colours are only for status.

Type
Pixelify Sans 700 · Room names
Pixelify Sans 500 · buttons, labels, pills
Atkinson Hyperlegible · chat and body text, chosen for legibility at small sizes.

Sizes: 12 / 14 / 16 / 20 / 26. In-world text: 6–7 px at map scale (≈ 18–21 px on screen).

Frame
Pixel card

3 px hard outline, inner bevel, offset shadow. No radius, no blur.

box-shadow: var(--frame-drop). Buttons get inset 0 -4px 0 as their "pressable" lip.
